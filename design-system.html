List Items

Rows used for lists that need a "which one is current" state plus hover-only secondary actions — currently the Versions list. The active row is marked by a faint accent-tinted background and bold name only (no separate indicator icon — a persistent dot/checkmark read as an unread or update badge, which was misleading here). Double-click the name to rename in place; hover reveals duplicate and delete icons on the right (delete is hidden entirely when it's the only remaining item — you can't delete the last version). The row has a fixed min-height: 32px so the icons appearing on hover never changes the row's height.

Main Floor
Ceremony Layout

Guest list grouped by each guest's first tag, using the same small-caps gray label style as section headers (.guest-group-label). Untagged guests are collected into their own group at the end rather than mixed in. Rows are name-only (no avatar) with tight vertical padding to keep more guests visible at once. Each group header shows a seated/total count (same convention as the overall stat) and a chevron that rotates between collapsed (pointing right) and expanded (pointing down) — click the header to toggle.
